# Football Manager — Android

Projeto Android que empacota a versão web do Football Manager em um aplicativo nativo via WebView.

## Como gerar o APK
1. Abra esta pasta no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Instale o Android SDK 35 quando o Android Studio solicitar.
4. Vá em **Build > Build APK(s)**.
5. O APK será gerado em `app/build/outputs/apk/debug/app-debug.apk`.

## Características
- Menu Novo Jogo / Carregar Jogo
- Países e divisões fictícias inspiradas em grandes ligas
- Clubes e jogadores fictícios
- Elenco, tática, mercado e classificação
- Partidas simuladas com campo visual e comentários
- Velocidade 1x/2x/4x
- Salvamento local
- Aplicativo em tela cheia e orientação horizontal

## Observação
Os nomes de clubes e jogadores são fictícios. O projeto é um protótipo de jogo e não usa marcas oficiais.
